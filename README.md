# Datastrukturer – starterprojekt (1. semester)

Åbn mappen som projekt i IntelliJ og markér `src` som *Sources Root*, hvis det ikke sker automatisk. Kræver Java 17 eller nyere.

| Pakke | Indhold |
|---|---|
| `dag1` | `Dag1Demo` (demo fra oplægget), `ListeOevelser` (opg. 1–5), `SetOgMapOevelser` (opg. 6–9) |
| `dag2` | `Sang` (opg. 1–4), `SangOevelser` (opg. 1–6) |
| `dag3` | `ListeEksperiment` (opg. 1–3), `SetEksperiment` (opg. 4–5) |
| `ugeopgave` | `Tekstanalyse` |

Opgavebeskrivelserne står i opgavesættet. Løs én opgave ad gangen, og kør programmet efter hver opgave.
